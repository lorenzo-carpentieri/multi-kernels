# Phase-Based Frequeny Scaling on Aurora
This folder contains all the scripts for reproducing the phase-based frequency scaling work on the Aurora cluster.
## Folder Structure
### **bash-pbs**
Contains scripts for running applications on Aurora using the PBS scheduler.
Curren implemented applications are: 
- ace
- aop
- metropolis
- mnist
- srad
The script in this folder are named submit_<app_name>.sh. Each script is specific to the application and contains the commands to run the application with the appropriate parameters.
### **run**
Contains scripts for running the applications.
#### Script: freq_scaling_profiling.py
This script run each application with all available frequency on the hardware. You can specify by command line the application to run. This is the first step that is needed to have the optimal frequency for each kernel in the applicaiton.

##### Script: freq_scaling_profiling.py: Input Description
```
--app-dir: Path to the folder containing the application executables (e.g., `/path/to/executables`).
--benchmarks: List of benchmark names to run (e.g., `ace aop metropolis`). Only benchmarks defined in the script will be executed.
--log-dir: Directory where log files for each application will be stored.
--pbs-path: Path to the folder containing PBS scripts for each application (e.g., `/path/to/pbs_scripts`).
--config-dir: Path to the directory containing the NONE configuration files for each application (e.g., `/path/to/config/none`).
```
##### Script: freq_scaling_profiling.py: Example Usage
```
python3 scripts/aurora/run/freq_scaling_profiling.py --app-dir=$(pwd)/build/ --benchmarks aop --log-dir=$(pwd)/data/aurora/logs/ --pbs-path=$(pwd)/scripts/aurora/bash-pbs/ --config-dir=$(pwd)/data/aurora/config/none/
```
#### Script: opt_freq_scaling.py
This script run each application with different configuration files: APP, KERNEL and PHASE. The configuration files are generated from the profiling step. 
##### Script: freq_scaling_profiling.py: Input Description
```
--app-dir: Path to the direcotry containing the application executables (e.g., `/path/to/executables`).
--benchmarks: List of benchmark names to run (e.g., `ace aop metropolis`). Only benchmarks defined in the script will be executed.
--log-dir: Directory where the final log files for each application will be stored.
--pbs-path: Path to the folder containing PBS scripts for each application (e.g., `/path/to/pbs_scripts`).
--config-dir: Path to the directory containing the configuration files for each application (e.g., `/path/to/config_files`).
```
##### Script: freq_scaling_profiling.py: Example Usage
```
python3 scripts/aurora/run/freq_scaling_profiling.py --app-folder=$(pwd)/build/ --benchmarks aop --log-dir=$(pwd)/data/aurora/logs/ --pbs-path=$(pwd)/scripts/aurora/bash-pbs/
```

### **parse-csv**
Contains the script for parsing the csv file generated from running script.
#### Script: parse_profiling.py
This script parse the data generated by freq_scaling_profiling.py and generates a CSV for each application that contains the time and energy values for all the frequencies. The script also generate a single CSV file with all applicaitons and kernels (Useful for saving a single file as backup).
##### Script: parse_profiling.py: Input Description
This script parse the data generated by freq_scaling_profiling.py and generates a single CSV file containing the results for all the application with each freqeuncy.
```
--log-dir=<path to the directory containing the log files for all the application> The lof files are generated by freq_scaling_profiling.py
--output-dir=<path to the directory where the output CSV files will be saved>
--benchmarks=<names of all the benchmarks to be processed>
```
##### Script: parse_profiling.py: Example Usage
```
python3 scripts/aurora/parse-csv/parse_profiling.py --log-dir=$(pwd)/data/aurora/logs-profiling/ --output-dir=$(pwd)/data/aurora/profiling-csv/ --benchmarks aop
```
#### Script: extract_opt_freq.py
This script extracts the optimal frequency for each kernel in the applications. The script extract also the optimal frequency for the entire application.
##### Script: extract_opt_freq.py: Input Description
This script extracts the optimal frequency for each kernel in the applications.
```
--csv-dir=<path to the directory containing the CSV files for all the application>
--output-dir=<path to the directory where the output files will be saved>
--benchmarks=<names of all the benchmarks to be processed>
```
Generates a CSV file for each application. The csv file contains the kernels with the optimal frequency for optimizing energy, edp ...
##### Script: extract_opt_freq.py: Example Usage
```
python3 scripts/aurora/parse-csv/extract_opt_freq.py --csv-dir=$(pwd)/data/aurora/profiling-csv/ --output-dir=$(pwd)/data/aurora/optimal-freq-csv/ --benchmarks aop
```
##### Script: generate_config.py
This script generates the configuration files for each application. The configuration files are generated based on the optimal frequency generated by the extract_opt_freq.py. The script generates three type of configuration files: APP, KERNEL and PHASE. The configuration files generated by this script should be manually modifed for adding some dummy kernels that are not profiled but are then used for changing the frequency in specific points of the application when the PHASE-aware approach is applied. (This is the only script that is not fully automated). In particular some effort is required for the PHASE configuratio file.
##### Script: generate_config.py: Input Description
This script extracts the optimal frequency for each kernel in the applications.
```
--opt-freq-csv-dir=<path to the directory containing the CSV files with the optimal freq. for each application and kernel> This files are generated by extract_opt_freq.py
--out-config-dir=<path to the directory where the configuration files will be saved>
--benchmarks=<names of all the benchmarks to be processed>
```
Generates a configuration file for each application. There are three type of configuration APP, KERNEL and PHASE.
##### Script: generate_config.py: Example Usage
```
python3 scripts/aurora/parse-csv/generate_config.py --profiling-csv-dir=$(pwd)/data/aurora/opt-freq-csv/ --out-config-dir=$(pwd)/data/aurora/config/ --benchmarks aop ace metropolis mnist srad
```
